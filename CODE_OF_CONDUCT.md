# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and assume good intent. Harassment, personal attacks and
demeaning comments aren't welcome here.

Report a problem to tarangrana48@gmail.com. Reports are handled privately, and
maintainers may remove comments, issues or contributors that break these rules.
